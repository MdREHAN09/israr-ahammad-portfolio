# Israr Ahammad — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Features
- Responsive dark-theme layout and mobile navigation
- Scroll reveal animations and reading progress bar
- Back-to-top button
- Project category filters
- Dark/light theme switch
- Copy-email interaction

## Run locally
1. Extract the ZIP and open this folder in Antigravity.
2. In the terminal run: `python -m http.server 5500`
3. Visit `http://localhost:5500`.

No npm install or build step is required.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
- Replace the GitHub and LinkedIn URLs with your own profile URLs.
- Add repository/live-demo links and a profile photo if desired.
- Review project descriptions and statuses for accuracy.
